# FOODBOLEROS - Donde cada bocado es un golazo 🍔⚽

Sitio web para el restaurante FOODBOLEROS, especializado en comidas rápidas con temática del fútbol profesional colombiano.

## Características 🌟

- Diseño responsivo para todos los dispositivos
- Interfaz moderna y elegante
- Menú interactivo
- Sección de contacto
- Animaciones suaves
- Temática futbolística

## Instalación 🚀

1. Clona este repositorio:
```bash
git clone https://github.com/tuusuario/foodboleros.git
```

2. Navega al directorio del proyecto:
```bash
cd foodboleros
```

3. Abre el archivo `index.html` en tu navegador web preferido.

## Requisitos de Imágenes 🖼️

Para que el sitio funcione correctamente, necesitas agregar las siguientes imágenes en la carpeta `img/`:

- `hero-bg.jpg` - Imagen de fondo para la sección hero (1920x1080px recomendado)
- `empanadas.jpg` - Imagen para el menú de empanadas (800x600px recomendado)
- `arepas.jpg` - Imagen para el menú de arepas rellenas (800x600px recomendado)
- `salchipapas.jpg` - Imagen para el menú de salchipapas (800x600px recomendado)
- `hamburguesas.jpg` - Imagen para el menú de hamburguesas (800x600px recomendado)
- `perros.jpg` - Imagen para el menú de perros calientes (800x600px recomendado)
- `dorilocos.jpg` - Imagen para el menú de dorilocos (800x600px recomendado)

## Personalización 🎨

Los colores principales del sitio se pueden modificar en el archivo `css/styles.css` ajustando las variables CSS en la raíz:

```css
:root {
    --primary-color: #1a1a1a;
    --secondary-color: #2c2c2c;
    --accent-color: #c59d5f;
    --text-color: #ffffff;
    --text-secondary: #b3b3b3;
}
```
